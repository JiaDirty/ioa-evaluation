# 项目资料导航

当前研究主线是**十项 Agent 模型行为安全测评**。十项类别以
`data/evaluation_catalog.yaml` 为唯一机器可读清单，当前文档以
[`当前方案/README.md`](当前方案/README.md) 为唯一人工入口。

5. [运行与判分指南](当前方案/运行与判分指南.md)：离线校验、烟测、真实运行和停止条件。
6. [判分与有效性规范](当前方案/判分与有效性规范.md)：VALID、模型行为、工具执行和最终影响边界。
