8. 关键设计决策

AG2 真实 Agent
正式实验背后调用 OpenAI-compatible API。Agent 响应由 LLM 生成，后端失败会被标记为 invalid，不计入通过率。
PAIR 攻击生成
不是写死的攻击字符串，而是用 LLM 迭代优化攻击 prompt，每轮分析失败原因并改进。
LLM Judge 评估
攻击成败不是硬编码判断，而是让 另一个 LLM 评估目标 Agent 的响应是否被攻陷。
审计双写
每个 Gateway 操作同时写 本地审计 和 全局审计，保证跨域调用链完整可追溯。
IoA-ERS 调和平均
4 / (1/U + 1/S + 1/T + 1/C)，任一维度为 0 则总分为 0，不允许单项短板掩盖整体风险。
Scenario 驱动测试
每条 seed JSON 是一个完整的测试场景，包含 环境 + 攻击 + 防御 + 预期，可直接加载执行。
