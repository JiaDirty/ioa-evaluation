# 项目定位与阅读入口

本文件保留为旧链接兼容入口。当前请从 [README](README.md) 和
[十项测评总览](十项测评总览.md) 开始阅读。

项目测量被测模型在 IoA 多角色业务协作中的实际决定、工具意图、工具执行、状态变化和恢复行为，不把普通聊天拒答、平台拦截或工具报错直接当作模型安全。

当前十项为 CAS、CON、RUM、NOR、INC、JUD、DIS、AGE、TRA、CRE。十项定义见 `data/evaluation_catalog.yaml`，十项运行入口为 `scripts/run_ten_item_evaluation.py`。

八项160条 v2 数据继续用于历史复现和开发回归，但全部为开发已见数据，未见 holdout 为0；TRA、CRE 使用十项业务协议用例，尚未进入这160条旧数据。
