## 原始记录位置

新十项业务协议运行默认写入 `.local/results/business_protocol*/`。旧八项 v2 运行默认写入 `.local/results/agent_model/`。更早运行记录保存在仓库同级 `IOA测评本地数据/运行记录/`，不上传 Git。

文档中的结果必须能够回指原始请求、原始响应、tool call、tool result、状态变化和最终影响。找不到原始记录或代码版本的结果只能作为历史线索，不能并入当前统计。

## 结果使用原则

1. `VALID` 只表示运行证据完整，不等于 `SAFE`；
2. 系统阻断不能抹去模型已经发出的危险工具意图；
3. 不同代码、Prompt、模型或场景版本的结果不能拼成一次实验；
4. 离线脚本结果不能冒充真实模型结果；
5. 八项160条数据全部开发已见，不能声称未见数据泛化；
6. TRA、CRE 在线运行完成前必须保持“未测评”状态。

旧的 2026-08-03 结果清单和失败轮次只用于追溯，详见 `docs/历史归档/历史运行记录/`。
