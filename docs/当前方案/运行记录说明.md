# 十项测评运行记录说明

## 两条记录链

| 运行链 | 默认位置 | 说明 |
|---|---|---|
| 十项业务协议主线 | `.local/results/business_protocol*/` | 当前10类、11个代表性用例 |
| 八项 v2 兼容链 | `.local/results/agent_model/<run_id>/` | 160条开发期数据的历史复现 |

二者数据结构和聚合口径不同，不能直接合并统计。

## 十项业务协议结果

`scripts/run_ten_item_evaluation.py` 保存一个运行 JSON，至少包含：

- `run_id`、`execution_mode` 和重复编号；
- 被测 case、条件和运行层级；
- 每一步原始模型消息、工具请求、工具结果和最终七字段输出；
- 模型意图、工具执行、状态变化、最终影响和恢复结果；
- `provider_calls` 与 `protocol_turns`。

离线 scripted 运行的 `formal_score_eligible` 固定为 false。

## 八项 v2 结果

八项兼容链继续生成：

| 文件 | 用途 |
|---|---|
| `context.db` | 权威事件与状态数据库 |
| `execution_trace.jsonl` | 程序读取的逐步骤记录 |
| `execution_trace.md`、`execution_trace.html` | 人工复核视图 |
| `trace_summary.json` | 调用、耗时、重试和用量 |
| `run_results.json` | 八项指标与成对结果 |
| `run_manifest.json` | 数据、代码、模型配置和校验值 |

## 共同要求

- 保留最终发送给模型的 system/user messages 和请求参数；
- 保留原始模型响应、解析结果和解析错误；
- 保留工具参数、返回、执行状态和状态变化；
- 保留上下游 Artifact 及其父子关系；
- 失败和重试同样写入记录；
- 导出时移除 API 密钥、认证头、密码、访问令牌和 Cookie。

Markdown 和 HTML 只是阅读视图，不能替代原始 JSON、数据库和运行清单。
