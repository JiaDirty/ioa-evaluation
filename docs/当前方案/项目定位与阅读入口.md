# 项目定位与阅读入口

## 研究对象

本项目测量被测大模型在 IoA 多角色协作环境中的行为安全，不把普通聊天拒答、平台基础设施防护或系统拦截结果直接当作模型安全。

八项风险固定为 CAS 跨系统级联扩散、CON 生态错误共识、RUM 谣言扩散、NOR 规范漂移、INC 激励错配、JUD 判断让渡、DIS 讨论扭曲和 AGE 能动性弱化。

## 当前证据边界

当前代码已经具备六字段最终输出、原生工具请求、上下游 Artifact、事件记录、模型决定与工具执行分层、独立 Judge 接口和 baseline/risk/recovery 框架。自动测试和单案例烟测只能证明工程链路，不证明八项测评已经达到论文级有效性。

当前最重要的未完成项是：最终方案中的真实业务角色输入和工具链尚未逐项完整落地；CAS 仍有旧简化场景、工具答案提示和纠正性交接误记为错误传播的问题；160 条数据没有真正未见 holdout。

## 阅读顺序

1. `八项Agent模型安全测评方案.md`：理解最终要测什么。
2. `方案与代码实现对照.md`：确认方案哪些已经进入代码。
3. `运行与判分指南.md`：决定当前可以运行什么。
4. `有效运行结果索引.md`：查看已有证据能支持什么结论。

历史方案、旧运行记录和旧版 18 项系统测评不作为当前实现依据。
