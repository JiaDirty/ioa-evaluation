IoA 安全测评系统架构图与详细流程图

本页面使用 HTML 和内嵌 SVG 绘制，不依赖 Mermaid。图中模块对应当前项目的风险测试、IoA 测评环境、攻击生成、Gateway、Registry、Agent、共享知识库、审计日志、大模型裁判和报告输出。

一、总体架构图

说明：图中上层是实验与风险测试，下层是 IoA 测评环境，右侧评估器负责把 Agent 输出、审计证据、知识来源和外部观测转换为可量化结果。

二、详细执行流程图

说明：流程图把不同测试的差异收敛到四类执行链路，分别是外部注册请求、真实任务链路、协议和 Agent 执行链路、行为和群体链路。所有链路最后都会进入证据收集、裁判和报告生成。

三、论文或 PPT 使用建议

如果用于 PPT，建议第一页放总体架构图，第二页放详细执行流程图。总体架构图适合说明系统由哪些模块组成，详细流程图适合说明一个风险测试如何真实运行并产生可复现实验数据。若需要转成图片，可以直接在浏览器打开本 HTML 后截图，或用浏览器打印为 PDF。
