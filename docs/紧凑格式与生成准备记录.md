## 生成阶段固定规则

- 每个测评类别单独请求。
- 小批量比较阶段每次只生成 1 条紧凑场景。
- 先比较多个模型，再确定主力模型。
- 生成结果只进入候选目录，不覆盖正式 `data\scenarios`。
- 顺序固定为：紧凑批次校验 → 展开 → 完整结构校验 → 语义/因果/重复检查 → 人工审核 → 纳入正式数据。
- 保存原始请求、原始响应、模型 ID、参数、Seed、Prompt 哈希和淘汰原因。
