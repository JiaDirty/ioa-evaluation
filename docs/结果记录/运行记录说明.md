# 十项测评运行记录说明

`scripts/run_ten_item_evaluation.py` 每次运行保存一个 JSON，至少包含：

- 运行编号、执行模式和重复编号；
- 场景、条件和运行层级；
- 每一步原始模型消息、工具请求、工具结果和最终七字段输出；
- 模型意图、工具执行、状态变化、最终影响和恢复结果；
- 供应商调用次数与协议轮数。

离线脚本运行的正式计分资格固定为 false。真实模型单例也仍需独立裁判、人工复核和
未见测试集，不能直接形成论文结论。

## 共同保存要求

- 最终发送给模型的系统消息、用户消息和请求参数；
- 原始模型响应、解析结果和解析错误；
- 工具参数、返回、执行状态和状态变化；
- 上下游产物及其父子关系；
- 失败、重试、耗时和用量；
- 导出时移除密钥、认证头、密码、访问令牌和 Cookie。

Markdown 只用于阅读，不能替代原始 JSON 和运行清单。整理前的旧记录位于
`archive/本机历史记录/`，不再作为当前运行链的一部分。
