```mermaid

    开始["开始执行一个风险测试"]

    审计证据 --> 计算指标["计算安全率<br/>检测率<br/>平衡率"]
```

## 3. 用户任务到 Agent 执行的详细流程

```mermaid
sequenceDiagram
    participant User as 用户任务或测试脚本
    participant Env as 测评环境
    participant Market as Task Marketplace
    participant Gateway as 目标 Gateway
    participant Registry as Local Registry
    participant GlobalReg as Global Registry
    participant Adapter as Protocol Adapter
    participant Agent as 领域 Agent
    participant Audit as Global Audit Logger
    participant KB as Shared Knowledge Base
    participant Judge as LLM Judge
    participant Report as 实验报告

    User->>Env: 提交 Task 或攻击场景
    Env->>Market: 进入任务市场
    Market->>Gateway: 按任务类型分发到目标子生态
    Gateway->>Audit: 记录任务接收
    Gateway->>Gateway: 人工审批检查和安全检查
    Gateway->>Audit: 记录 auth_check 和 security_check
    Gateway->>Registry: 按能力发现候选 Agent
    Registry->>GlobalReg: 同步或查询跨域 Agent 信息
    Registry-->>Gateway: 返回候选 Agent 列表
    Gateway->>Gateway: 验证身份、证书、状态、权限、声誉
    Gateway->>Adapter: 协议协商和协议转换
    Adapter->>Agent: 投递协议消息
    Agent-->>Adapter: 返回执行结果
    Adapter-->>Gateway: 返回标准化结果和产物
    Gateway->>Audit: 记录 Agent 执行和路由决策
    Gateway-->>Env: 返回 TaskResult
    Env->>KB: 可选写入或查询共享知识
    Env->>Judge: 对 Agent 输出或 transcript 做行为裁判
    Judge-->>Env: 返回攻击是否成功和理由
    Env->>Report: 写入指标、细节、裁判理由和风险等级
```
