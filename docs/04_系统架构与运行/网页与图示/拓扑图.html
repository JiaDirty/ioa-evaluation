IOA 系统完整拓扑图

当前系统是单机受控 IOA testbed：通过 TaskMarketplace、Gateway、Registry、ProtocolAdapter、HTTP endpoint、Audit、Decision Agents 串起真实测评链路。

一、实验控制层

ExperimentRunner运行实验，汇总 18 项测评结果
IoAEnvironment创建 Sub-IoA、注册 Agent、维护环境状态
TopologyController控制 full_mesh / star / chain 跨域拓扑
MetricsEngine计算通过率、安全率、审计完整性等指标
risk_tests18 个 IOA 风险测评入口

二、攻击与判定层

AttackInjector生成攻击 prompt：泄露、越权、谣言、绕过审批等
RegistryAttackSurface外部注册/篡改入口：身份伪装、能力膨胀、声誉操纵
SemanticMismatchSimulatorA2A/MCP/Private API 语义错配探针
GatewayRoutingOverride中心节点路由操纵探针
LLMJudge / DeterministicJudge判断攻击是否在输出行为上成功

三、全局 IOA 基础设施层

TaskMarketplace任务分发入口：单域、跨域、多跳、产物复用
Global Registry全局 AgentCard 注册表
Global AuditLogger全局审计链，支持 query_chain / compute_metrics
SharedKnowledgeBase共享知识库：错误共识、谣言、知识冲突测评
LocalAgentEndpointServer本地 HTTP endpoint，承接 A2A/MCP/Private API 投递

四、Gateway 内部安全链路

Task Intake接收任务并写入审计
TaskUnderstandingAgent任务意图、领域、敏感级别
PermissionAnalysisAgent权限 scope 与审批敏感度
HumanAgencyAgent人工审批与判断让渡检测
PolicyEngine硬规则授权，必要时 fail-closed
Registry Discovery按能力、领域、声誉发现候选 Agent
Identity Verification证书与 ACTIVE 状态校验
CapabilityMatchingAgent已验证候选排序
ProtocolNegotiatorA2A/MCP/Private API 协商
ProtocolAdapterHTTP endpoint 投递
Artifact生成任务产物
Post Security Agents内容安全、来源可信、共识风险

五、协议互操作层

ProtocolNegotiator选择协议，检测降级风险
A2AAdapterofficial core JSON-RPC/HTTP 子集
MCPAdapterMCP 协议投递与语义错配测试
PrivateAPIAdapter私有 API 投递与弱协议测试

七、主要数据流

正常任务流： risk_tests → ExperimentRunner → IoAEnvironment → TaskMarketplace → Gateway → Registry discovery / verify_identity → CapabilityMatchingAgent → ProtocolNegotiator → ProtocolAdapter → LocalAgentEndpointServer → Agent runtime → Artifact → Post-security Decision Agents → AuditLogger → MetricsEngine
攻击测评流： AttackInjector / RegistryAttackSurface / SemanticMismatchSimulator / RoutingOverride → Registry / Gateway / Protocol / Knowledge / Agent endpoint → Artifact 或 Audit evidence → LLMJudge / DeterministicJudge → TestResult.details → Metrics
跨域通信流： Source Gateway → TopologyController 检查拓扑 → relay_to_sub_ioa → Target Gateway → Target Local Registry → Target Agent endpoint → Global Audit + Local Audit 双写
