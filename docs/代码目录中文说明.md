# 代码目录中文说明

代码目录和 Python 模块名必须保持英文，否则会破坏导入路径。本文件提供对应的中文用途。

| 路径 | 主要用途 |
|---|---|
| `api/` | FastAPI 接口，接收任务、查询运行状态和读取记录 |
| `config/` | 模型、Judge、工具、MCP、权限和存储配置 |
| `data/agent_model_cases/` | 八项 Agent 模型安全测评的分类案例，每类 20 个 |
| `data/seeds/` | 旧版系统风险测评的基础任务数据 |
| `frontend/` | React 前端控制台 |
| `risk_tests/` | 旧版风险测试的具体检查逻辑 |
| `scripts/` | 数据生成、校验、运行测评、导出记录和重新判定脚本 |
| `src/agents/` | Agent 卡片、Agent 创建和模型接入 |
| `src/audit/` | 事件记录与审计 |
| `src/core/` | 公共数据结构和基础类型 |
| `src/evaluation/agent_model/` | 八项 Agent 模型安全测评核心实现 |
| `src/evaluation/agent_model/categories/` | CAS、CON、RUM、INC、JUD、NOR、DIS、AGE 八类流程 |
| `src/evaluation/agent_model/tools/` | 八项测评使用的本地受控工具 |
| `src/gateway/` | Agent 选择、权限检查和执行入口 |
| `src/judging/` | 旧版系统测评的判定与证据处理 |
| `src/llm/` | 模型接口配置、请求、token 检查和错误处理 |
| `src/mcp/` | MCP 工具服务接入 |
| `src/observability/` | 运行步骤、时间线和可观察数据 |
| `src/orchestration/` | 任务规划、执行图和 Agent 调度 |
| `src/persistence/` | SQLite 任务、事件、工具和产物存储 |
| `src/protocol/` | A2A、MCP 和私有接口协议路由 |
| `src/runtime/` | AG2、LLM、HTTP 和人工 Agent 的统一运行层 |
| `src/security/` | 授权、委托边界和安全检查 |
| `src/tasks/` | 后台任务队列和生命周期 |
| `src/tools/` | 普通任务使用的 ToolGateway 和工具注册 |
| `sub_ioas/` | Sub-IoA 示例和配置 |
| `tests/` | 自动测试和回归测试 |

## 八项测评主要入口

- 命令入口：`scripts/run_agent_model_suite.py`
- 案例加载：`src/evaluation/agent_model/case_loader.py`
- 总调度：`src/evaluation/agent_model/suite_runner.py`
- 单个 Agent 步骤：`src/evaluation/agent_model/step_executor.py`
- 输入拼接：`src/evaluation/agent_model/context_builder.py`
- 输出解析：`src/evaluation/agent_model/behavior_parser.py`
- Judge：`src/evaluation/agent_model/judge.py`
- 证据构建：`src/evaluation/agent_model/evidence_builder.py`
- 易读记录导出：`src/evaluation/agent_model/trace_export.py`

## 不应手工修改的本机运行目录

- `results/`：真实或离线测评结果；
- `evidence/`：部分旧流程生成的证据；
- `data/ioa_runtime.sqlite3`：本机运行数据库；
- `.venv/`：Python 虚拟环境；
- `frontend/node_modules/`：前端依赖。

这些目录已被 Git 忽略。需要清理时应先确认运行已经停止并保留重要结果。
