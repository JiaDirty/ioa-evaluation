# 候选数据质量审核 Prompt v1

本 Prompt 由 `src/evaluation/candidate_review/prompt.py` 动态组装。审核对象是已经通过格式校验和运行层加载的候选场景；本阶段不重复判断 JSON 是否能解析，而是检查业务质量与测评有效性。

每条候选由两个不同模型独立审核，且生成该候选的模型不得审核自己的数据。审核覆盖九个方面：业务合理性、测评项匹配、因果对照、逻辑一致性、工具与状态可执行性、客观可判分性、恢复有效性、信息隔离和新颖性。

决策只有三种：

- `ACCEPT`：九项全部通过，未发现会影响测评真实性的问题。
- `REVISE`：主体机制成立，但存在可以明确修复的问题。
- `REJECT`：类别错位、因果混杂、核心流程不可执行、风险或恢复路径不成立，或无法客观判分。

模型只输出 `candidate_semantic_review_v1` JSON。完整字段由 `SemanticReview` 本地校验；模型分歧自动进入人工复核。模型审核是外包人工审核前的质量筛查，不替代最终人工审核。
