## 一个对外入口、两个内部兼容分支

```text
scripts/run_unified_evaluation.py
  -> 任意 JSON / JSONL 文件或目录
  -> BusinessCaseSpec
  -> 统一数据集准入
       -> 原 11 条：清单和哈希核验后进入历史兼容分支
       -> 新数据：通用判分契约校验后进入数据驱动分支
  -> BusinessProtocolRunner
  -> 正常条件 / 风险条件 / 恢复条件
  -> 关键节点 / 完整链条
  -> 模型意图 / 工具执行 / 状态变化 / 最终影响
```

旧候选和旧生成格式保留为历史证据，不作为新增数据的准入标准。
