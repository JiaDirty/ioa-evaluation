# 作者格式覆盖试跑第 01 轮

## 目的

本轮验证简洁作者格式、通用判分契约和本地编译器能否覆盖全部十类测评，而不是生产正式数据集。八个候选生成模型分别对 11 个可运行测评项生成 1 条，共执行 88 个任务。

## 结果

初次调用得到 25 条可直接展开候选、56 条本地校验不通过候选和 7 条接口或输出截断失败候选。使用最新版编译器对已保存响应重新编译后，额外恢复 2 条，最终有 27 条进入语义审核候选集，61 条未进入候选集。

| 生成模型 | 最终通过确定性准入 |
| --- | ---: |
| GPT 5.6 Sol | 10 / 11 |
| Gemini 3.7 Flash | 5 / 11 |
| GPT 5.6 Luna | 4 / 11 |
| 智谱 5.3 Flash | 4 / 11 |
| Claude Opus 5 | 3 / 11 |
| DeepSeek V4 Pro | 1 / 11 |
| DeepSeek V4 Flash | 0 / 11 |
| 通义千问 3.8 Flash | 0 / 11 |

27 条候选覆盖情况如下：信任与授权链 8 条、跨系统级联扩散 4 条、判断让渡 3 条、规范漂移 3 条、能动性弱化 2 条、讨论扭曲 2 条、谣言扩散 2 条、激励错配 1 条、生态错误共识 1 条、资格申报 1 条。

## 验证

统一入口成功加载 27 条通用契约候选，共 114 个智能体步骤，计划生成 54 组正常/风险运行结果；校验阶段没有调用被测模型。候选全部使用 `generic_scoring_v1`，未发现重复数据。项目全套测试为 `187 passed`。

作者层文件平均约 37 KB，展开后的完整运行数据平均约 42 KB，平均缩减约 11%。这说明作者层已经去掉部分机械重复，但仍然偏重，不能据此开始 440 条正式扩量。

## 证据边界

“通过确定性准入”只表示字段、依赖、工具效果、典型安全/危险路径和通用判分规则能够在本地自洽运行，不表示业务语义、现实合理性、自然语言质量或论文代表性已经通过审核。27 条仍需跨模型语义预审和人工审核；61 条失败数据保留原始请求、响应和错误证据，不覆盖、不删除。

本轮原始证据位于 `data/candidate_batches/批量生成-第03轮-作者格式覆盖试跑/`，准入候选位于 `data/candidate_datasets/第03轮-作者格式覆盖试跑/`。
