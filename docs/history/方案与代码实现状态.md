## 一个输入、一个状态中心、一个流程控制器

```text
scripts/run_evaluation.py
  -> 任意 JSON / JSONL 文件或目录
  -> BusinessCaseSpec
  -> 统一数据集准入
  -> BusinessProtocolRunner
  -> 正常条件 / 风险条件 / 恢复条件
  -> 关键节点 / 完整链条
  -> 模型意图 / 工具执行 / 状态变化 / 最终影响
```

生产数据先由 `scripts/migrations/migrate_scenario_tasks_v1.py` 规范化为 `ScenarioTask`，再由
`scripts/run_pipeline.py` 通过唯一 `PipelineOrchestrator` 推进。候选生成
脚本位于 `scripts/migrations/`；正式运行器已经移除固定判分入口。
